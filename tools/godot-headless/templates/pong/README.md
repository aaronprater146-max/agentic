# Arena Pong

A compact Pong game against a computer opponent. It is generated by the
`godot-headless` Arena toolbox tool and has no external art or plugin
dependencies.

## Play

- **Desktop:** move the left paddle with **W/S** or **Up/Down**.
- **Touch devices:** touch and drag vertically to steer the left paddle.
- The computer controls the right paddle. Scores appear at the top.

## Project structure

- `scripts/pong_simulation.gd` is the deterministic game model.
- `scripts/main.gd` renders the model and handles keyboard/touch input.
- `tests/headless_confirmation.gd` exercises collisions, AI movement, scoring,
  and court bounds inside the Godot engine without a display.
- `export_presets.cfg` configures the supported binary targets.

## Configured targets

| Target | Configuration | Notes |
| --- | --- | --- |
| Windows 10/11 | 64-bit Windows Desktop preset | Produces an `.exe` when matching Godot export templates are installed. |
| Android 9+ | API level 28 minimum; `arm64-v8a` and `armeabi-v7a` | Uses Godot's Compatibility renderer and a Gradle export. Android SDK/JDK and matching templates are required to build an APK. |

The project source is portable, but this source bundle deliberately does **not**
contain Godot binaries, Android SDK files, JDKs, export templates, signing keys,
or `.godot` import caches.

## Headless verification

From an Arena workspace with a Godot 4.7-compatible headless editor:

```sh
python3 godot_headless.py confirm \
  --godot /path/to/godot \
  --project /path/to/arena-pong \
  --report /path/to/confirmation.json
```

A passing run exits zero and includes `PONG_CONFIRMATION_PASS` in the report.
See the toolbox tool README for the complete ephemeral workflow, including
source-building a temporary headless editor if an official binary is not
available.
