# SYSTEM PURGE — Sound & Music Sources (v0.4)

## Current build: SFX-ONLY (no music)
Music was removed for now. All sound effects are **synthesized live** with the
Web Audio API (electric tether zap, dubstep wobble bass, convolution reverb,
sub drops, dash whooshes, key fanfares…), so there are zero licensing issues
and the game works fully offline.

## Royalty-free banks for a future OST
- **Sonniss GDC Game Audio Bundles** — studio-grade SFX, royalty-free, no
  attribution: https://gdc.sonniss.com/
- **Kenney Audio Packs** (UI, Impact, Sci-Fi…) — CC0: https://kenney.nl/assets?q=audio
- **Freesound** — filter by `Creative Commons 0`: https://freesound.org
- **OpenGameArt** — CC0 music/SFX search: https://opengameart.org
- **Pixabay Music** — free, no attribution: https://pixabay.com/music/
- **Incompetech (Kevin MacLeod)** — CC-BY 4.0, attribution required: https://incompetech.com
- **SoundImage (Eric Matyas)** — royalty-free with attribution, huge dark/
  sci-fi/industrial catalog: https://soundimage.org
