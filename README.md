# agentic

Unreal Engine tooling for agentic AI workflows.

## ArenaAgent (UE 5.8.3 plugin)

An editor plugin that makes **Arena.ai** an agent inside the Unreal Editor: a persistent, dockable
chat panel with saved/clearable conversation history, talking to an OpenAI-compatible API and driving
the editor through real tools — creating Blueprints of all types, components, variables, functions and
events, spawning actors, managing assets and running editor Python.

See [`ArenaAgent/README.md`](ArenaAgent/README.md) for setup and usage.
