PERSISTENT PROJECT CONTEXT AND DECISIONS
----------------------------------------
- `agentic` is durable storage for reusable headless Arena tools and finished
  products. Arena execution state is disposable.
- The durable toolbox is `tools/`; machine/human indexes are
  `tools/toolbox.json` and `tools/TOOLBOX.md`.
- A tool is fetched at a confirmed ref into a marked temporary workspace, run
  headlessly, validated, then removed only after its product is persisted.
- New products go in `WORK/`, not legacy `products/`. Each needs artifact,
  README, target/build status, compact provenance, checksum, and an immutable
  raw GitHub download URL after publication.
- `TOOL_LOG.txt` is the canonical catalog. `ARENA_LOG.txt` is the local editable
  copy; replace this worklog at checkpoints rather than overwriting the catalog.
- Never commit runtimes, Android SDK/JDK files, export templates, caches,
  `.godot` import state, signing material, or secrets.
